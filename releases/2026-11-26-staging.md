## Scope
1. UI split. The UI is a separate service, built from its own repository and released as its own image, pinned by digest. The hive serves the API only. The two are released independently and are compatible while their API major versions match and the hive's minor version is at least the UI's. The split went to staging on 24 November; this is the first release that carries UI changes made in the separate repository.
2. Proof of concept for the UI/UX pipeline. This release tests the path from a design file to a released UI: the design's colours and layout are exported, converted into the UI's theme and frame, reviewed against fixed checks, and released. [omegahive-ui#238](https://github.com/omega-flagship/omegahive-ui/pull/238), [omegahive-ui#239](https://github.com/omega-flagship/omegahive-ui/pull/239).
3. Simple and Pro modes. The Pro mode switch is active. Pro mode on is the existing UI (Classic, the default). Pro mode off is the new simple mode (Omega). A person with no saved choice gets Pro mode. [omegahive-ui#243](https://github.com/omega-flagship/omegahive-ui/pull/243).

## Added
1. Omega experience (simple mode), selected with the Pro mode switch: top bar, menus, phone frame and Ask box. Omega Home has no screens yet. [omegahive-ui#238](https://github.com/omega-flagship/omegahive-ui/pull/238), [omegahive-ui#239](https://github.com/omega-flagship/omegahive-ui/pull/239), [omegahive-ui#241](https://github.com/omega-flagship/omegahive-ui/pull/241), [omegahive-ui#243](https://github.com/omega-flagship/omegahive-ui/pull/243).
2. Settings: Start setup over, which resets the signed-in person's own account. For members, Settings shows only this row. [omegahive#705](https://github.com/omega-flagship/omegahive/pull/705), [omegahive-ui#245](https://github.com/omega-flagship/omegahive-ui/pull/245).
3. Onboarding: the setup route and onboarding progress are saved in one transaction (API 1.3). [omegahive#757](https://github.com/omega-flagship/omegahive/pull/757).
4. A mind can show content on the screen of the person it is answering. [omegahive#325](https://github.com/omega-flagship/omegahive/pull/325).
5. Artifacts: a generated picture opens as a picture, with source, SVG and PNG downloads. [omegahive#552](https://github.com/omega-flagship/omegahive/pull/552).
6. Inbox: Allow and Deny with a single "Don't ask again" option. [omegahive#502](https://github.com/omega-flagship/omegahive/pull/502).
7. A mind can ask another mind it can see; the reply returns to the asking conversation. [omegahive#554](https://github.com/omega-flagship/omegahive/pull/554).
8. Create: a change to an app made by Create runs as a round of the same plan, with undo and put back. [omegahive#510](https://github.com/omega-flagship/omegahive/pull/510).
9. Create: a page can reach the sites it declares once its owner allows them. [omegahive#750](https://github.com/omega-flagship/omegahive/pull/750).
10. Swarm logs are hash chains with a published head. [omegahive#28](https://github.com/omega-flagship/omegahive/pull/28).
11. Federation: hives share their own observations as signed bundles, weighted by trust. [omegahive#33](https://github.com/omega-flagship/omegahive/pull/33).
12. Minds can run code in the sandbox shell. [omegahive#721](https://github.com/omega-flagship/omegahive/pull/721).
13. Installer: prebuilt SWI-Prolog for Linux x86_64 and Windows; no GCC download on Windows. [omegahive#718](https://github.com/omega-flagship/omegahive/pull/718), [omegahive#742](https://github.com/omega-flagship/omegahive/pull/742).

5. Limits: a call waits for calls in flight instead of being refused; a spending pause ends when its limit has room. [omegahive#625](https://github.com/omega-flagship/omegahive/pull/625).

8. Research stays within its limits and reports instead of stalling. [omegahive#696](https://github.com/omega-flagship/omegahive/pull/696).
9. A mind builds software through Create unless its owner enables its own coding. [omegahive#395](https://github.com/omega-flagship/omegahive/pull/395).

11. Create: the waiting line shows a mind's state before a spending refusal. [omegahive#752](https://github.com/omega-flagship/omegahive/pull/752).
12. Create: with Studio set up, a page's design goes to Studio. [omegahive#736](https://github.com/omega-flagship/omegahive/pull/736).
13. Create: a plan starts from a saved creation only where its owner can see it without the admin override. [omegahive#755](https://github.com/omega-flagship/omegahive/pull/755).
14. Create: designs are kept up to 16,000 characters; a fix round's brief truncates failing output last. [omegahive#735](https://github.com/omega-flagship/omegahive/pull/735).
15. Apps: a swarm's owner turns an app on or off in that swarm; a made app goes to its maker's own swarm. [omegahive#747](https://github.com/omega-flagship/omegahive/pull/747).
16. People: a hive reachable only from its owner's computer explains why others cannot join. [omegahive#263](https://github.com/omega-flagship/omegahive/pull/263).
17. Hive map: names with characters beyond Latin-1 use Inter; the first-visit hint is placed after the names are shown. [omegahive-ui#240](https://github.com/omega-flagship/omegahive-ui/pull/240), [omegahive-ui#244](https://github.com/omega-flagship/omegahive-ui/pull/244).
18. Tools skills can run on a relocated SWI-Prolog. [omegahive#268](https://github.com/omega-flagship/omegahive/pull/268).

## Fixed
1. Direct OpenAI models, including the default, receive max_completion_tokens instead of max_tokens. [omegahive#712](https://github.com/omega-flagship/omegahive/pull/712).
2. A mind replies to the person who wrote to it before resting, or the person is told it stopped. [omegahive#310](https://github.com/omega-flagship/omegahive/pull/310).
3. A mind sends every research request a message asks for. [omegahive#744](https://github.com/omega-flagship/omegahive/pull/744).
4. A turn that failed in the runtime is retried with its original input. [omegahive#723](https://github.com/omega-flagship/omegahive/pull/723).
5. A Code request and its helper are charged against the hive's total, not separate budgets. [omegahive#684](https://github.com/omega-flagship/omegahive/pull/684).
6. The Mac Code service has its own home directory, so git ignores the user's git configuration. [omegahive#322](https://github.com/omega-flagship/omegahive/pull/322).
7. Flows: the cancel rule reads FINISHED, and a prompt waits for its resume. [omegahive#42](https://github.com/omega-flagship/omegahive/pull/42).
